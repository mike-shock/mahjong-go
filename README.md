# Маджонг на Go + Fyne

Запуск: `go mod tidy`, затем `go run .`.
Сборка: `go build -o mahjong .`.
Нужны Go 1.22+, C-компилятор и системные зависимости Fyne.
На Debian/Ubuntu: `sudo apt-get install golang-go gcc libgl1-mesa-dev xorg-dev`.

Плитки оформлены как в веб-версии: цифры и 萬 / 竹 / ● для мастей,
東 / 南 / 西 / 北 для ветров, 中 / 發 / 白 для драконов, 花 / 春 для цветка и сезона.
Рисунки встроены в исполняемый файл через go:embed; устанавливать китайский
шрифт и копировать папку assets рядом с готовой программой не требуется.
При сборке из исходников папка assets необходима.

Рисунки получены из Noto Sans CJK (SIL Open Font License 1.1).
